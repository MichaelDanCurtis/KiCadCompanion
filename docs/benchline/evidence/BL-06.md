## Implementation and boundaries

`server/workflows.mjs` implements versioned SQLite schema creation inside a transaction, WAL with FULL synchronization, plans/tasks/dependencies, attempts, scoped approval references, input revisions, outputs, evidence and ordered events. A second SQLite database holds an exclusive OS lock for the store lifetime; it prevents a second process from recovering a live writer while allowing journal commits. Crashes release the owner lock; uncertain document locks remain in the durable journal. There is no automatic non-idempotent replay.

Approved-but-undispatched attempts recover as interrupted. Executing attempts recover as unknown-outcome. Recorded output remains verifying and resumes through the verification adapter only. Qualified outcome observation can identify an applied result for verification or a confirmed absent write for a separately reviewed new attempt. Missing/unknown observation does not clear the lock. Staleness remains separate from historical state.

Workflow records confer no ActionGate authority. Mutating adapters require an explicit approval reference and a host-owned authorization callback; none are installed in production. The existing BL-04 action journal and recovery rules remain separate and unchanged. Native-document locks are scoped to this workflow database, not a machine-wide CAD mutex. Future native adapters must share the existing native action boundary and canonical document identity; the current work does not claim native authoring integration.

`server/workflow-projects.mjs` registers three real read-only adapters for requirements, saved artifacts and the overall registered-input review. These observe the existing ProjectStore. The Verification page exposes proposals, prerequisites, current/stale evidence, attempts and recovery controls. Browser mutation routes require the BL-05 controlling window. Plans check only registered inputs, not engineering correctness, live editor state or physical acceptance. Evidence is stored locally; no native design file is written.
