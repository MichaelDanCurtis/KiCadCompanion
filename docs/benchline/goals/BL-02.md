# BL-02 — Inventory licenses and commercial dependencies

Status: verified for inventory/report scope, 2026-09-05; not legal clearance or persistent host Goal activation. Phase: Foundation.
Prerequisites: BL-01. Read [the shared execution contract](../GOALS.md) before starting.

## Outcome

Produce a version-specific dependency and asset inventory plus a commercially flexible integration recommendation, with every unknown explicitly recorded.

## Scope and reuse

Read-only dependency/source/terms review, local reports, and bounded implementation of the inventory checker and its synthetic tests. Do not modify third-party source or activate external CI services. This goal completes an audit and local check, not legal clearance or a license selection.

Reuse first: package.json; package-lock.json; THIRD_PARTY.md; docs/RELEASE_REVIEW.md; scripts/review-check.mjs.

## Deliverables

- Machine-readable SBOM and license/notice inventory covering shipped transitive dependencies, fonts, Python/native helpers, tool binaries, and proposed FreeCAD/firmware integrations.
- Decision record for external integration versus bundling/forking, including Konnect contribution terms and vendor model/example-code rights.
- CI/check command rejecting unclassified newly shipped dependencies and missing required notices.

## Acceptance criteria

- [x] **BL-02-A1** — Each in-scope dependency has exact version, source, declared license, use/distribution mode, and known obligations or an explicit unresolved classification.
- [x] **BL-02-A2** — MIT/BSD/ISC/Apache preference and individual copyleft review are encoded as review policy, not a claim that permissive wrappers erase transitive obligations.
- [x] **BL-02-A3** — Vendor documents, footprints, STEP models, and sample firmware are inventoried separately from application code; absent redistribution permission is not inferred.
- [x] **BL-02-A4** — No project license, CLA, commercial contract, trademark clearance, or redistribution permission is accepted on the owner's behalf.
- [x] **BL-02-A5** — The audit's unknowns have named decisions and release gates; report completion never labels the product legally approved.

## Verification

Reconcile inventory against lockfile and actual release inputs; inject an unknown dependency/asset fixture and verify the check flags it. Source citations must identify fetched date and relevant version.

Record each criterion in [the evidence record](../evidence/BL-02.md) using the shared template. That record is created when work starts; absence means no evidence yet. Record commands, exit codes, tool versions, input/output revisions, before/after observations, and any manual test steps. A baseline failure remains a finding, not an excuse to delete or skip a required test.

## Blockers and authority

Inaccessible terms or missing provenance are recorded findings; they block later distribution, not completion of an honest inventory.

## Non-goals

No license change, purchase, external contribution, or legal certification.
