# BL-10 — Create editable FreeCAD enclosures with revision checks

Status: proposed; not activated. Phase: Disciplines.
Prerequisites: BL-04, BL-06, BL-07, BL-08. Read [the shared execution contract](../GOALS.md) before starting.

## Outcome

Generate and revise a native parametric FreeCAD enclosure from a verified board/module envelope while preserving manual edits and evidence of mechanical checks.

## Scope and reuse

One supported FreeCAD version, disposable native document, approved board assembly export, and a bounded enclosure template.

Reuse first: Adapter/action contract, project revision graph, A2UI diagnostics, actual-render provenance. Add a separate FreeCAD adapter; do not require CadQuery.

## Deliverables

- FreeCAD adapter for document identity, observation, selection, preview/execute/verify, and native save/export.
- Named native sketches/features and exposed parameters for wall thickness, clearances, mounting, connector openings, and lid.
- Board-to-mechanical coordinate contract with explicit units, origin, orientation, tolerances, and artifact hashes.

## Acceptance criteria

- [ ] **BL-10-A1** — Native document reopens with editable named sketches/features; importing a final STEP solid alone does not satisfy editability.
- [ ] **BL-10-A2** — Automated dimension checks verify mount-hole alignment, connector opening positions, enclosure envelope, and minimum clearances against approved numeric requirements.
- [ ] **BL-10-A3** — Solids are valid and intentional interferences/cable/fastener access are reported; print orientation, material, tolerances, and unmodeled components are explicit.
- [ ] **BL-10-A4** — A manual FreeCAD edit is observed and invalidates a stale AI proposal; reapplying cannot silently overwrite it. Coordinate fixtures cover rotation, back-side parts, and mm/inch mismatch.
- [ ] **BL-10-A5** — Exported STEP and print mesh agree with the saved native revision; missing component geometry prevents an unqualified fit-pass claim.

## Verification

Native create/save/reopen/manual-edit journey, FreeCAD geometry assertions, stale-plan test, coordinate-transform fixtures, and visual inspection of actual assembly. No print is required for this software gate.

Record each criterion in [the evidence record](../evidence/BL-10.md) using the shared template. That record is created when work starts; absence means no evidence yet. Record commands, exit codes, tool versions, input/output revisions, before/after observations, and any manual test steps. A baseline failure remains a finding, not an excuse to delete or skip a required test.

## Blockers and authority

Unknown mechanical dimensions, missing STEP assets/rights, incomplete API or undo semantics, or an unapproved enclosure tolerance profile.

## Non-goals

No claim of physical fit, print submission, simulation certification, smooth bidirectional CadQuery round-trip, or complete mechanical editor replacement.
