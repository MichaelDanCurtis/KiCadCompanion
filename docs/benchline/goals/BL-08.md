# BL-08 — Prove safe electronics authoring and model assignment

Status: in-progress under the 2026-09-11 narrow sourcing deferral in [the execution amendment](../ROADMAP_EXECUTION.md). Phase: Disciplines.
Prerequisites: BL-04, BL-06, BL-07. Read [the shared execution contract](../GOALS.md) before starting.

## Outcome

Author or update a small approved reference circuit through KiCad/Konnect and verify model-only assignment without changing unrelated PCB content.

## Scope and reuse

Disposable reference project and approved Konnect extension checkout if required. Schematic, PCB, library, and model actions must use validated Konnect MCP operations; inspect installed skill and current schemas first.

Reuse first: server/konnect.mjs; server/observer.py; context()/select(); server/renders.mjs; model-audit.py; tests/live-smoke.mjs and render-live-smoke.mjs.

## Deliverables

- Capability matrix and version-pinned compatibility tests for schematic creation, placed-board observation/editing, model assignment, checks, and export.
- Narrow model-only operation or a documented existing equivalent, with preview/revision guard/undo/verification. A missing capability is not worked around with text edits.
- One small module carrier/reference circuit with source-backed symbols/footprints and actual populated render.

## Acceptance criteria

- [ ] **BL-08-A1** — Create/reopen the reference schematic and board through supported tools; run ERC/DRC on saved revisions and record every finding with disposition rather than suppressing checks.
- [ ] **BL-08-A2** — Before/after model assignment shows only intended model-reference/transform changes; pad identities, nets, placement, orientation, layers, graphics, and unrelated fields are preserved.
- [ ] **BL-08-A3** — Front/back footprints, non-default transforms, missing/hidden/DNP models, and real library fields that previously caused rejection have explicit fixtures.
- [ ] **BL-08-A4** — Undo restores the pre-edit state; stale-plan, unsupported-field, and failed-partial-operation fixtures make no unauthorized changes.
- [x] **BL-08-A5** — The populated actual render records exact saved-board/model provenance; AI illustration is optional and remains visibly separate from engineering evidence.

## Verification

Real KiCad-produced fixtures, semantic before/after comparisons, undo/reopen tests, live IPC smoke, saved ERC/DRC reports, and actual render coverage. Capture library/tool versions.

Record each criterion in [the evidence record](../evidence/BL-08.md) using the shared template. That record is created when work starts; absence means no evidence yet. Record commands, exit codes, tool versions, input/output revisions, before/after observations, and any manual test steps. A baseline failure remains a finding, not an excuse to delete or skip a required test.

## Blockers and authority

Missing safe model API or lossless preservation; no manual source-file fallback. Upstream fork/CLA/publication requires a separate owner-approved scope and terms review.

## Non-goals

No customer-board mutation by default, full autorouter, high-speed HDMI/HEC validation, PCB certification, or automatic PR submission.
